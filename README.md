# Euscorpius website

This repository contains the generated static website served by GitHub Pages at [www.euscorpius.com](https://www.euscorpius.com).

The site source and build workflow are maintained separately in the private [EuscorpiusWebsiteSource](https://github.com/Euscorpius-com/EuscorpiusWebsiteSource) repository. Changes to the website should be made there; GitHub Actions builds the site and publishes the generated files to this repository.

The `CNAME` file configures the custom domain. Keep it in the repository root.
